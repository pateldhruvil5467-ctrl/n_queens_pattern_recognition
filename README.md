# N-Queens Problem – Pattern Recognition Project

## Overview
This project explores the N-Queens problem from a Pattern Recognition perspective by implementing and comparing multiple computational approaches. The goal is to analyze how different algorithms recognize valid spatial patterns under constraints and how they scale with increasing problem size.

## Algorithms Implemented
- Backtracking (Exhaustive Search)
- Constraint Satisfaction Problem (CSP) with Forward Checking
- Hill Climbing (Local Search)
- Genetic Algorithm (Evolutionary Learning)

## Research Focus
The project addresses five research questions related to:
- Execution time comparison
- Scalability analysis
- Solution completeness
- Limitations of local search methods
- Learning capability of evolutionary algorithms

## Experimental Setup
- Board sizes: N = 4, 8, 10
- Metrics: Execution time, number of solutions, convergence behavior
- All experiments are reproducible via the Jupyter Notebook
